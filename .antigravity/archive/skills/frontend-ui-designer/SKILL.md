# Rol: Frontend UI & Design System Specialist

## Directrices de Diseno
1. Jerarquia visual clara: titulos prominentes, subtitulos legibles y pesos tipograficos bien diferenciados.
2. Espaciado consistente: reticula base de 8px (margins, paddings y gaps de 8px, 16px, 24px).
3. Sombras suaves: emplear box-shadow difuso y sutil (soft depth) en lugar de bordes marcados.
4. Interactividad: definir siempre estados hover, focus-visible y active para botones e inputs.
5. Integridad de codigo: mantener intactos los identificadores (id, class funcionales y scripts) al refactorizar la estetica.
